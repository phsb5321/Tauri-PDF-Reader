Per project rules, **none of these may be marked passed until Pedro actually runs Lectrice.** This file is the script.

## Notes / known gaps

- **Audio-finished detection is now WIRED** (PR 038): the player's dedicated audio thread fires `on_finished` when the rodio sink drains; `AiTtsEngine::set_finished_callback` (wired in `lib.rs` setup) emits `ai-tts:finished`; the frontend completes off that event instead of the `elapsed >= totalDuration` timer estimate. The headless half is asserted in `karaoke-sync.test.ts` ("completes off the ai-tts:finished event even when the duration is unknown" — the counterpart to the 026 guard test). **Step 9 below is the remaining GUI confirmation** (rodio drain timing on a real device). 026's `isPlaybackComplete` guard stays as the timer fallback for the known-duration path.
- **Speed 2×–4.5×** is out of scope here (rodio `set_speed` shifts pitch; needs pitch-preserving DSP).
- rodio playback is not unit-testable → steps 3–6 are the only proof.
