# Private corpus identity manifest

The real-book acceptance corpus is private, external input. Neither its files,
absolute path, titles, hashes, sizes, nor page-level content belongs in git.

The runner expects this local file beside the corpus:

```text
<LECTRICE_REAL_PDF_CORPUS>/.lectrice-manifest.json
```

It is mode `0600` on the operator host and follows this schema:

```json
{
  "pdfs": [
    {
      "basename": "private.pdf",
      "sha256": "64 lowercase hex characters",
      "size": 123,
      "pages": 10
    }
  ],
  "epub": [
    {
      "basename": "negative-control.epub",
      "sha256": "64 lowercase hex characters",
      "size": 123
    }
  ]
}
```

At runtime, `scripts/corpus-enumerate.mjs` streams each external file to derive
its SHA and size. `e2e/run-corpus-journey.sh` joins that result to the external
manifest, refuses unknown or changed inputs, and records only bounded local
receipts. It never prints the corpus root. Temporary app-scoped copies are
removed by the exit trap; no screenshots or book bytes enter result artifacts.

The previously committed concrete metadata file was removed on 15/08/2026.
History still contains that metadata; rewriting published history is destructive
and requires a separate owner-approved incident procedure. No book bytes or
private absolute source path were committed.
