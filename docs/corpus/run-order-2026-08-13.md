   scoped render
   c. `card-open` phase — library-surface cover content-hash (NC5), card
   total == manifest, card click mounts reader
   d. `verify` phase — resume lands page 2 of N (row-wins oracle), Ctrl+L
   toggle-library, delete + confirm, target-row-absent (title), IPC
   row-gone (ipcDocumentRowPageByTitle == null)
   e. post-verify cache checks — covers/{SHA}-\* gone, tts pre/post counts
   f. cover-hashes.tsv row + cover-tie (rendered == cached)
4. **Negative controls (always, after books):** corrupt-control (hermetic
   garbage → PDF_INVALID), epub-control (manifest-validated EPUB →
   PDF_INVALID after bounded settle).
5. **Cross-book:** cover-hashes exact count == PDF_COUNT (NC3), all hashes
   mutually distinct (NC5 cross).
6. **Summary:** failures.tsv + per-phase logs + cover-hashes.tsv retained;
   exit = `FAILED || GUARDS_FAILED`.

## 3. Stop conditions

### FATAL — stop immediately, exit 3 (no further books)

- manifest missing / pdf sha mismatch / epub sha mismatch / zero PDFs /
  missing pages entry (runner's own FATALs).
- cargo build failure; toolchain_exec failure; corpus dir unreadable.

### HARD STOP — halt the run, record, investigate (never auto-continue)

- **Harness panic** in ANY phase log (`REFUSING TO BOOT`, WebKitGTK crash,
  tauri-driver missing, bindings-export panic) — the harness is broken, more
  books add noise.
- **Xvfb/DISPLAY failure** at lane start.
- **First-book open phase product defect** — reader never mounts on book 1
  (all books share the open path; a failure here is systemic, not per-book).
- **2 consecutive book failures** of any kind — infrastructure smell.
- **Cover phase unexpectedly BLOCKED after covers merged** — regression in the
  merged surface; stop, do not record 5× BLOCKED noise.
- **Disk < 20% free** (vm103 R1 lesson; a full run needs ~10 G headroom).
- **Heavy-gate lost / another lane waiting** — do not starve siblings.

### SOFT STOP — per-book, record and continue (run ends non-green)

- Single phase failure (open/card-open/verify) — record basename+sha+phase+
  command to failures.tsv AND issue #120 (never book content).
- cover-tie / cover-coverage / cover-distinct failures — recorded; cross-book
  checks still run to completion for evidence.
- corrupt/epub control failure — recorded; loop completes for evidence.
