## Preconditions

   any tracked or untracked worktree change.
2. `bash scripts/corpus-negative-controls.sh` passes (23/23).
3. `nix develop -c tauri-driver --help` succeeds from the committed flake.
4. The external PDF/EPUB corpus matches its private `.lectrice-manifest.json`.
5. The heavy gate is held; packaged lanes do not overlap.

## Per-book order

1. Verify basename, size, and SHA against the external private manifest.
2. Copy the input into a fresh temporary app-data profile and re-hash the copy.
3. Rebuild Vite and rerun the Tauri build script so the exact dialog-seam path
   is embedded for this input.
4. **Open:** real toolbar control; exact title and page count; production canvas
   completion for pages 1 and 2; text-backed TTS when page 2 has selectable
   text (image-only front matter is explicitly recorded as not applicable).
5. **Card-open:** target card reaches real-cover `ready`; displayed decoded RGBA
   hash equals cached PNG decoded RGBA hash; card page count matches; real
   double-click restores and renders page 2.
6. **Verify:** restart on the same profile; row reports page 2 of N; resume
   renders page 2; hover reveals delete; product invokes confirmation exactly
   once; DOM and read-only IPC both prove the row is gone.
7. Verify the SHA-keyed cover file is gone after deletion.

After all books, the corrupt PDF and EPUB must surface `PDF_INVALID`. Cover
rows must equal PDF count and all decoded RGBA hashes must be distinct.
`failures.tsv` must be empty and process exit must be zero.

## Stop conditions

- **Fatal immediately:** dirty source, identity mismatch, missing manifest/page
  count, zero PDFs, missing EPUB control, toolchain/build failure, unexpected
  profile root, or missing ImageMagick pixel oracle.
- **Failed run:** any phase, cleanup, cover-tie/count/distinctness, confirmation,
  corrupt control, or EPUB control fails. Continue only where the runner does
  so to retain bounded diagnostic evidence.
- Missing selector, display, driver, oracle, or confirmation call is failed,
  never skipped-green.
