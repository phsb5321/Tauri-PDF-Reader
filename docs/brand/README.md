# Lectrice brand assets

**Vermilion nightingale on paper.** The bird carries meaning, never chrome.
Identity artwork uses paper `#F4EFE4`, vermilion `#C8462C`, and ink `#14110D`
for type. Wordmark: Fraunces 600, `opsz=144`, `SOFT=0`, `WONK=1`.
See [brand rules](brand-spec.md). Product UI tokens are a separate system;
this identity package does not change them.

From the repository root, with Python/uv and Chrome or Chromium installed:

```sh
uv run --with playwright==1.63.0 --with pillow==12.3.0 python docs/brand/render-github.py
uv run --with playwright==1.63.0 --with pillow==12.3.0 python docs/brand/render-github.py --check
```

`CHROME_BIN=/absolute/path/to/chromium` selects a browser explicitly. Without
that override the renderer finds system Chrome/Chromium, then falls back to
Playwright's installed Chromium. Reference renders use Chrome 152.0.7977.82 at
DPR 1. `--check` renders into disposable scratch and compares **all PNG pixels**
without overwriting the saved evidence; browser/font-rasterizer drift fails.
Render dependencies are tooling only, not added to the product lockfile.
The temporary server binds loopback, is closed on exit, and the browser blocks
non-local requests. Fonts and art load without internet; the first `uv` install
may need internet.

## Apply to GitHub — owner action, not done by this PR

A committed image **does not configure GitHub**. After review/merge:

1. Download [the social PNG](../../.github/assets/lectrice-social-preview.png)
   using **Download raw file** (not a screenshot of GitHub's image viewer).
2. Open [repository Settings](https://github.com/phsb5321/Tauri-PDF-Reader/settings).
3. Under **Social preview**, choose **Edit → Upload an image…** and select
   `lectrice-social-preview.png`. Retain the complete 2:1 composition.
4. Verify that Settings shows the new bird/wordmark card. Link-preview caches on
   other platforms can lag; saving a file or merging this PR proves neither upload
   nor external cache refresh.

GitHub's [official instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)
recommend 1280×640 and a PNG/JPG/GIF under 1 MB. This PNG is opaque paper, keeping
its appearance stable on light/dark host surfaces.

**Avatar:** this repository belongs to `phsb5321`; repositories do not have a
separate configurable avatar. Do **not** replace the owner's personal avatar to
brand this one repo. If a dedicated Lectrice organization/account is used, its
owner can open that organization's **Settings → Profile → Profile picture →
Edit → Upload a photo…**, select `lectrice-avatar.png`, keep the full square in
the crop editor, and save. The platform supplies the circular crop. No account,
organization, ownership transfer, avatar, or repository setting is changed here.

## Archive / deliberately absent

- [Original brand board](lectrice-brand.html) records the earlier chevrons,
  Space Grotesk and Catppuccin exploration. It is **historical, not v2 guidance**.
- No decorative issue/PR headers: the repository has no contribution templates
  needing them, and a bird above every form would turn identity into chrome.
- No generated raster is shipped as source art; PNGs are deterministic exports
  of vector/HTML compositions. No product code, icon module, app tokens or
  settings changes, speculative UI screenshots, account-free/offline-TTS claims,
  or app behavior/release-readiness claims.
